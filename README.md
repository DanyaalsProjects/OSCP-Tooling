# oscp-tooling

Python utilities I'm building from scratch during OSCP prep, the start of a
longer move into application security. Grows from small scripts toward a
working nmap parser with argparse over the course of the month.

## Contents
- `scanparse.py` — parses nmap output into structured results (in progress)
- `appsec-notes.md` — for each web vuln I hit: the likely vulnerable code, and the fix

## Note
No target data, credentials, or scan output from any lab or exam lives here.
